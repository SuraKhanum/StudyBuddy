# StudyBuddy

A simple command-line study planner built with Python.

## Features
- Add study tasks
- View tasks with numbering
- Mark tasks as done
- Delete tasks
- Tasks are saved in a file, so they stay after closing the program

## Technologies Used
- Python
- JSON (for saving data)

## How to Run
1. Install Python
2. Download StudyBuddy.py
3. Run: python StudyBuddy.py
